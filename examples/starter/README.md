# Starter

A minimal Spec Kit project (`specs/` and `.specify/`) that Specwright can read. You can copy it into a project:

```bash
cp -r examples/starter/specs examples/starter/.specify /path/to/your/project/
```

In a real project these files are written by Spec Kit's `/speckit-constitution`, `/speckit-specify`, `/speckit-plan` and `/speckit-tasks`. Point your MCP client at Specwright (see the main README) and ask your agent to call `list_features`.
